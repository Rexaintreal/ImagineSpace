# ImagineSpace

3D reconstruction pipeline from drone footage using CUT3R.

## Structure
- ``src/preprocess/`` frame extraction, blur filtering
- ``src/reconstruction/`` CUT3R integration
- ``src/scale_correction/`` scale accuracy validation
- ``src/viewer/`` point cloud viewing
- ``journal/`` dated development log
- ``data/sample_footage/`` actual video files gitignored, see below

## Data
Sample footage sourced from YouTube for testing; not committed to repo.
